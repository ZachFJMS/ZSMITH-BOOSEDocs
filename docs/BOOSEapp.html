Namespace BOOSEapp

Classes

AppBOOSEException

Handles the exceptions that occur within the BOOSE application. Provides error messages for components and outputs them to the canvas.

AppCanvas

Provides drawing functionality for the BOOSE application, implementing the BOOSE.ICanvas interface. Handles drawing shapes, moving the cursor, setting colors, and rendering text on a bitmap surface.

AppCircle

Represents a command that draws a filled circle on the application canvas using a specified radius.

AppCommandFactory

Provides a factory for creating BOOSE command objects based on command names. Responsible for instantiating the correct command class corresponding to a given keyword.

AppDrawto

Represents a command that draws a line from the current cursor position to a specified point on the application canvas.

AppMoveto

Represents a command that moves the drawing cursor to a specified position on the application canvas.

AppParser

Responsible for parsing user input into BOOSE commands. Interacts with the command factory to create commands and the stored program to execute them.

AppPen

Represents a command that sets the pen color on the application canvas using RGB values.

AppRect

Represents a command that draws a rectangle on the application canvas using specified width and height.

AppTri

Represents a command that draws a triangle on the application canvas using specified base length and height.

AppWritetext

Represents a command that writes a specified text string to the application canvas.
